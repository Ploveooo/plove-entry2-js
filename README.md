# Plove Entry 2 JS

Public runtime JavaScript channel for Plove entry 2.

- `home-app.js`: current runtime JavaScript
- `version.json`: version and SHA-256 manifest

The iOS app verifies the SHA-256 value before executing a remote update and falls back to its bundled JavaScript if the remote update cannot be used.

Do not place credentials, tokens, private API keys, device IDs, or backend secrets in this repository.
